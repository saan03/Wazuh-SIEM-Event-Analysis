# Wazuh-SIEM-Event-Analysis

This project demonstrates the deployment of a Security Information and Event Management (SIEM) solution using Wazuh 4.11.2 to monitor both Linux and Windows environments. It includes hands-on setup, real-time agent communication and simulation of common security events in a virtual lab.

Learning Outcome

- Gained practical experience deploying a SIEM solution  
- Learned real-time threat monitoring and log analysis using Wazuh  
- Developed troubleshooting and network visibility skills through hands-on simulation
